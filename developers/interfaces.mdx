# Interfaces

This page lists the Tumbuh contract surface that external integrators can call from a wallet, a smart contract, or a backend. Every signature here matches the deployed contract source.

<Note>
This page is hand-maintained today. A future CI job will regenerate the function-signature blocks from NatSpec via `solidity-docgen`. The hand-written **Events and indexing recipes** section will remain manual.
</Note>

<Warning>
**Do not call the vault directly.** Deposit and redemption flow through the [TumbuhRouter](#tumbuhrouter-user-entry-points). The vault's `deposit` and `redeem` are gated to the Router; its `mint` and `withdraw` revert with `NotImplemented()`. Standard ERC-4626 integrations that auto-pick `withdraw` will fail — route through the Router's `redeemWithSwap` instead.
</Warning>

## TumbuhRouter — user entry points

```solidity
function depositWithSwap(
    uint256 idrxAmount,
    address receiver,
    uint256 minSharesOut,
    bytes calldata swapData
) external whenNotPaused nonReentrant returns (uint256 shares);

function redeemWithSwap(
    uint256 tidrxAmount,
    address receiver,
    uint256 minIdrxOut,
    bytes calldata swapData
) external whenNotPaused nonReentrant returns (uint256 idrxAmount);
```

## Events and indexing recipes

The following events are the reliable hooks for off-chain indexing. All are emitted by Tumbuh contracts (not the external strategies).

### Position lifecycle

```solidity
// Emitted by TumbuhRouter
event DepositWithSwap(
    address indexed sender, address indexed receiver,
    uint256 idrxAmount, uint256 idrxToSwap, uint256 idrxIdle,
    uint256 usdcAmount, uint256 shares
);
event RedeemWithSwap(
    address indexed sender, address indexed receiver,
    uint256 tidrxAmount, uint256 sharesToRedeem, uint256 usdcAmount,
    uint256 idrxFromSwap, uint256 idleToReturn
);
```

**Indexing recipe (user positions).** Subscribe to both events filtered by `receiver` to track per-user net deposits and withdrawals. Augment with on-chain reads of `router.getUserVaultShares(user)` and `vault.convertToAssets(...)` for current value.

### Strategy state

```solidity
// Emitted by StrategyManager
event FarmStrategyAdded(uint256 indexed strategyId, address adapter, address vault);
event FarmStrategyRemoved(uint256 indexed strategyId);
event StrategyPercentagesUpdated(/* ... */);
event UpdateStrategy(/* ... */);
event RewardCompounded(uint256 indexed strategyId, address rewardToken, address urd, uint256 claimed, uint256 usdcAmount);
event EmergencyWithdrawSuccess(uint256 indexed strategyId, uint256 recovered);
event EmergencyWithdrawFailed(uint256 indexed strategyId);
event EmergencyStrategyReset(uint256 indexed strategyId);
event StrategyReactivated(uint256 indexed strategyId);
```

**Indexing recipe (strategy registry).** Snapshot `getAllFarmStrategiesInfo()` at indexer start, then subscribe to `FarmStrategyAdded`, `FarmStrategyRemoved`, `UpdateStrategy`, and `StrategyReactivated` to keep the local registry in sync.

### Fees

```solidity
// Emitted by TumbuhVault
event PerformanceFeeCollected(uint256 profit, uint256 feeAssets, uint256 feeShares, address treasury);
event PerformanceFeeUpdated(/* ... */);
```

**Indexing recipe (fee history).** Subscribe to `PerformanceFeeCollected` to compute realized treasury accruals over time.
